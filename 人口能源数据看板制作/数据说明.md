# 全国人口与能源年度数据

## 模块简介

为人口与能源消费交互看板整理的官方年度数据集。数据来自[国家统计局国家数据·全国年度数据](https://data.stats.gov.cn/dg/website/page.html#/pc/national/yearData)，本次获取日期为 **2026-10-29**。

本文件保留数据下载、清洗和核验的详细说明。交互看板的运行与操作见[模块首页](README.md)，本模块独立保存在仓库的 `人口能源数据看板制作/` 目录中。

## 数据覆盖

| 项目 | 范围 |
| --- | --- |
| 原始查询范围 | 2008—2025 年，共 18 年 |
| 当前看板展示期 | 2011—2025 年，共 15 年；人均生活用能最新两年缺失 |
| 看板同比辅助年 | 2010 年；原始数据仍保留 2008—2025 年 |

| 人均生活能源消费量 | 本次查询有值至 2023 年，2024、2025 年为空 |
| 官方原始指标 | 40 项，包含核心指标及同表备用指标 |
| 原始年度单元格 | 720 个，其中 671 个有值、49 个为空 |
| 核心指标 | 15 项；初次完整窗口为 2009—2023 年，当前 2011—2025 年窗口的人均生活用能最新两年缺失 |

这里的截止年只描述本次查询库响应，不代表其他官方渠道未发布更晚年份。没有将空值填成零，也没有插值。覆盖表中的首年是本次查询范围的首个非空年，不是该统计指标最早发布年份。

各年度宽表保留 2008—2025 年完整查询范围。当前看板按年份选择 2011—2025 年，不再使用初次数据核验时的 in_display_window 标记筛选；该历史标记仍表示 2009—2023 年核心指标齐全的窗口。2024、2025 年已有指标正常展示，人均生活用能缺失时显示断点与提示。

## 获取与复现

从项目根目录使用已有 Python 环境：

```powershell
python "人口能源数据看板制作/scripts/fetch_nbs.py"
python "人口能源数据看板制作/scripts/prepare_data.py"
```

下载脚本仅使用 Python 标准库，调用新版页面使用的公开指标目录和数据查询接口，不需要登录。下载返回的 JSON 原始字节直接保存，清洗过程不改写这些原始文件。

重新运行下载会刷新本目录的数据快照和获取时间；如需保留此次版本，请先另存本模块目录。只重新清洗时运行第二条命令即可，无需联网。

独立核验脚本需已有 `openpyxl`，用于只读检查 Excel：

```powershell
python "人口能源数据看板制作/scripts/verify_data.py"
```

`scripts/build_workbook.mjs` 用于生成 Excel 整理版，依赖 `@oai/artifact-tool`。它不是读取 CSV 或运行看板的必需依赖。本地工具依赖目录不纳入 Git。

## 统计口径与计算

- 地区为全国，地区代码 `000000000000`。人口统计范围与修订说明以原始指标定义为准，人口数为年末时点值，不做多年累计。
- 年龄统一为 0—14 岁、15—64 岁、65 岁及以上。官方年龄表说明 2011—2019 年数据按 2020 年人口普查修订。
- 城镇人口比重与年龄占比由相应人数除以年末总人口计算，标为计算值，不冒称另行下载的官方占比。
- 能源结构采用煤炭、石油、天然气、一次电力及其他能源。最后一类保留官方原名，不直接改称“清洁能源”或“非化石能源”。
- 品种折标量估算值 = 能源消费总量 × 官方占比 ÷ 100，单位为万吨标准煤。实物煤炭、原油、天然气、电力等指标保留在原始长表中，单位不同，不相加。
- 能源较上年变化 =（本年总量 ÷ 上年总量 − 1）× 100。本次取得的指标未单列官方可比增速，因此官方增速字段为空；自算变化不等同官方可比增速，不由弹性系数反推。
- 人均生活能源消费量直接使用官方值，采用官方年平均人口分母口径，不用全国总能源除以年末人口代替。
- 比较基期的增量可按各品种估算折标量作算术分解，同时单列舍入差额变化，使瀑布合计与总变化一致。这不是人口或能源类别的因果贡献分析。

官方统计口径调整说明可参考[2024 年统计公报注释](https://www.stats.gov.cn/xxgk/sjfb/tjgb2020/202502/t20250228_1958817.html)。不要将不同下载版本的历史数值直接拼接。

## 验证与已知差异

初次数据核验确认 15 项核心指标在 2009—2023 年完整。现看板为展示最新数据采用 2011—2025 年，2010 年用于首年变化计算，人均生活用能的 2024、2025 年保留为空。程序核对来源文件哈希、年份与指标唯一性、城乡及性别加总、年龄分组、人口自然变动和能源占比。独立脚本逐项核对原始响应与保存 CSV，并核对 Excel 缓存计算值。

两处差异保留：

- 2018 年年龄分组加总比总人口少 1 万人，未修改原始人数或强制归一占比。
- 2019 年四类能源占比合计 99.9%，原占比保留；相应折标量差额单独计算，不分摊到某种能源。

备用指标的缺失列于覆盖表。当前 2011—2025 年窗口中，人均生活用能最新两年缺失只影响对应图表，其他已有指标正常显示。Excel 预览已逐表检查；本文件记录数据准备与核验，看板截图和交互检查见[看板验收记录](看板验收记录.md)。

## 来源与引用

数据提供方：国家统计局。查询页面、官方指标 ID、分类 ID、原始定义、获取时间与 SHA-256 校验值随数据保存。页面导出功能也基于同类查询结果生成文件，本次以接口 JSON 作为原始快照，CSV 与 Excel 是可复现的整理结果。

本项目代码、整理结果与官方原始数据应区分标注；引用或再发布数据时保留国家统计局来源、获取日期及统计口径说明。
