# 数据可视化看板｜第四章

[返回项目首页](../README.md)

## 模块简介

参考《Excel数据可视化——从图表到数据大屏》第四章，使用 Python、Matplotlib 与 Tkinter 实现人力资源和销售两个看板。将 17 个图表与指标组件组合为完整布局，支持看板切换、销售月份筛选、原尺寸查看及图片与指标导出。

## 案例与功能

| 看板 | 组件 | 交互方式 |
| --- | --- | --- |
| 人力资源 | 6 个：年龄、性别、婚姻、学历、总人数及入转调、部门分布 | 静态人员快照、原尺寸查看与导出 |
| 销售 | 11 个：类别销量、销量环比、全年销售额趋势、商品销售额 Top3、利润率、区域销量、快递销量及 4 个成本卡片 | 1—12 月筛选、联动更新、原尺寸查看与导出 |

销售看板默认 9 月，全年销售额趋势始终展示完整 12 个月。人力资源看板对应 2022 年 3 月快照，不提供月份切换。

## 环境与运行

已验证 Windows、Python 3.13、Matplotlib 3.10.1、NumPy 2.2.3、openpyxl 3.1.5、Pillow 11.1.0 与 Tkinter。中文字体使用微软雅黑；跨平台字体与窗口适配尚未验证。依赖见 [requirements.txt](requirements.txt)，已有满足依赖的环境可跳过安装。

以下命令均在项目根目录执行：

```powershell
python -m pip install -r "第四章数据可视化看板/requirements.txt"
python "第四章数据可视化看板/app.py"
```

保留根目录的两份源工作簿及文件名。顶部切换看板或销售月份，窗口等比例缩放；“原尺寸查看”支持滚动检查细节。

“导出PNG及数据”在本章 `输出/手动导出/` 保存完整分辨率图片与同名 JSON 聚合指标，文件名带时间戳，不覆盖先前导出。

## 实现方式

openpyxl 只读加载源工作簿，Python 完成分类计数、月份筛选、金额汇总与排名，Matplotlib 绘制组件并组合看板，Tkinter 显示渲染结果与处理控件。日常运行不需要启动 Excel、不执行 VBA，也不需要联网。

## 数据来源与统计口径

源文件位于项目根目录：[人力资源工作簿](../第四章%20人力资源可视化看板.xlsx)、[销售工作簿](../第四章%20销售看板参考.xlsx)。

| 指标 | 原始范围 | 统计方式 |
| --- | --- | --- |
| 人员结构 | `202203人员基础信息!A2:H1471` | 记录计数与分类汇总 |
| 月销售额、利润额、销量 | `销售明细!A2:J8565` | 按月筛选，金额与利润求和、订单计数 |
| 区域、快递、产品类别 | 销售明细 C、D、H 列 | 当前月分类订单数 |
| 商品 Top3 | 销售明细 I、E 列；`统计数据!S2:S347` | 产品销售额降序，并列按源产品表顺序 |
| 成本及占比 | `成本明细!A2:C49` | 当月分类成本及其占比 |
| 默认值核对 | `统计数据!D2:O30`、`X3:Z5` | 核对 9 月缓存，不以缓存替代业务计算 |

关键口径与修正：

- 人员统计沿用原表记录计数，共 1470 条记录、1375 个不同编号、87 组重复编号，无完全重复记录；不按编号自动去重。
- 源工作簿 `K24:K25` 的学历公式引用颠倒。Python 根据 D 列明细统计为专科以下 170 人、专科 282 人，其他学历不变，原工作簿不修改。
- 年龄按 18—24、25—29、30—34、35—39、40 岁及以上分组，保留参考图“40=<”标签。显示百分比采用余数分配，合计 100%；人数和扇区角度使用未舍入数据。
- 销售明细包含 2021 年的 8564 条唯一订单。“销量”沿用订单数口径，不等同于商品件数。销售额和利润额除以 10000，以“万”展示。
- 成本源表未注明单位，保留原数值；利润直接汇总销售明细，不以单位不明的成本重新推算。
- 销量环比为本月订单数÷上月订单数−1，修正参考图“同比”误标。1 月缺少上年 12 月数据时显示“不可计算”。
- Top3 根据当前月全部产品销售额排序，避免源表排名范围漂移与并列查找缺项；默认 9 月结果与参考图一致。

## 验证与已知差异

提供[人力资源整屏对照](逐图对照/HR_整体.png)、[销售整屏对照](逐图对照/Sales_整体.png)和 17 张独立组件对照。默认组件已逐张视觉检查，另检查了 1 月、12 月边界显示与两个实际桌面窗口。详细结论见[逐图验收记录](逐图验收记录.md)。

在项目根目录运行验证与预览生成：

```powershell
python "第四章数据可视化看板/test_chapter4.py"
python "第四章数据可视化看板/export_previews.py"
```

既有测试包含 5 组，覆盖人员统计、9 月缓存核对、12 个月独立聚合、138 个组件状态、13 个整屏渲染、Tk 控件与导出，并检查文字边界与源文件哈希不变。全年状态经过程序测试，不代表所有月份均逐张人工检查。

销量环比条形保留参考图截断坐标，不能按条长比例判断订单数，应以标注值为准。实现修正了部分金额与标签的不必要换行，月份控件位于窗口顶部，奖牌由 Matplotlib 形状绘制。字体抗锯齿、少量文字位置与图标细节存在差异，不承诺逐像素一致。
