## 运行方式

使用已有Python环境，不需要新建环境或重复安装依赖。PowerShell运行：

```powershell
python -X utf8 "第四章数据可视化看板/app.py"
```

在其他电脑上，保留本章目录及上一级的两份源Excel，安装[requirements.txt](requirements.txt)中的依赖后，在本章目录执行 `python app.py`。目前验证环境为Windows、Python 3.13、Matplotlib 3.10.1、NumPy 2.2.3、openpyxl 3.1.5、Pillow 11.1.0及Python自带Tkinter；中文字体使用微软雅黑，跨平台字体与窗口尚未验证。

顶部切换“人力资源看板”和“销售看板”。销售看板可选择1—12月，默认9月；人力资源是2022年3月静态人员快照，没有虚构月份数据。窗口自动等比例缩放，“原尺寸查看”支持滚动检查细节。“导出PNG及数据”在本章 `输出/手动导出/` 保存完整分辨率PNG及同名JSON聚合指标，文件名带时间戳，不覆盖之前的导出。

Matplotlib根据原始数据绘制图表，Tkinter显示渲染结果并处理控件；没有用Excel截图作为看板背景或冒充Python绘图。日常运行不需要Excel，不运行VBA，不联网。

## 数据口径与原图差异

1. **学历人数按用户选择纠错。** 原工作簿 `202203人员基础信息!K24:K25` 的公式引用颠倒。Python按D列明细统计：专科以下170人、专科282人，其余学历不变；原Excel不修改。
2. 人员数按原表COUNTA口径统计1470条记录，不擅自按编号去重。源数据有1375个不同员工编号，87组编号重复，但没有完全重复的人员记录；这些是教学源数据的质量限制。
3. 年龄区间按18—24、25—29、30—34、35—39、40岁及以上划分，保留原图“40=<”标签。整数百分比采用余数分配，使各项显示值合计100%，人数及扇区角度使用未舍入数据。
4. 销售明细共8564条记录，日期均在2021年，订单号均不重复。原表“销量”通过COUNTIFS计数，Python沿用订单数口径，不按“订单额÷单价”推算产品件数。销售额、利润额除以10000，与原图“万”单位一致。
5. 成本取自 `成本明细!A2:C49`，单位在源表中未注明，因此保留原数值，不擅自标注为元或万元。利润额直接汇总销售明细G列，不用单位不明的成本表重新推算利润。
6. 原图“销量环比”下误写“同比”，Python改为“环比”，公式为本月订单数÷上月订单数−1。1月缺少上年12月数据时显示“不可计算”，不使用当年12月代替。环比条形沿用原图截断坐标的表现方式，不应按条长比例判断订单数，实际数值为准。
7. Top3按当前月全产品销售额降序排序，金额相同则保持源产品表顺序，不让原表RANK范围逐行漂移或并列VLOOKUP缺项影响结果。默认9月Top3与原图一致。
8. 修复源图成本金额、百分号和“总销量”的不必要换行；保留数值精度和整体布局。月份操作控件移到窗口顶部，图内显示当前月份。奖牌用Matplotlib形状重绘，字体抗锯齿、少量文字位置和图标细节与Excel有差异，不声称逐像素一致。

## 文件结构

- `app.py`：桌面入口、月份切换、等比例显示、原尺寸查看与PNG/JSON导出。
- `data_model.py`：只读Excel、数据校验与聚合计算。
- `charts.py`：两个看板及17个独立图表组件。
- `test_chapter4.py`：数据、渲染、窗口与导出测试。
- `export_previews.py`：默认图、边界月示例和左右对照生成。
- `输出/`：两个默认看板、1/2/12月销售示例、组件图与窗口截图。
- `Excel参考图/`、`逐图对照/`：原图和比较材料。
- `inspect_sources.py`、`inspect_excel.ps1`、`export_references.ps1`、`check_window.py`：本地检查工具，不属于日常运行步骤。Excel导出工具只读打开源表，关闭不保存；生成的本地检查JSON默认不纳入Git。
