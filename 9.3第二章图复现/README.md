# 图表绘制｜第二章

[返回项目首页](../README.md)

## 模块简介

参考《Excel数据可视化——从图表到数据大屏》第二章，使用 Python 读取源工作簿并绘制 30 个图表案例。覆盖基础图形、渐变效果、组合图与极坐标图，支持单图绘制和批量生成，尽量保留参考案例的数据、配色、标签与布局。

## 环境与运行

已验证 Windows、Python 3.13。依赖见 [requirements.txt](requirements.txt)，中文字体使用 Windows 的微软雅黑。已有满足依赖的 Python 环境可以直接使用，无需重新安装。

以下命令均在项目根目录执行：

```powershell
python -m pip install -r "9.3第二章图复现/requirements.txt"
python "9.3第二章图复现/运行全部30图.py"
```

单独绘制第 1 图，或绘制第 15—20 图：

```powershell
python "9.3第二章图复现/复现第01图_渐变柱形图.py"
python "9.3第二章图复现/复现第07至30图.py" --start 15 --end 20
```

结果默认保存在本章目录。第 7—30 图脚本还支持通过 `--front`、`--back` 和 `--output-dir` 指定输入工作簿与输出目录。

## 实现方式

openpyxl 读取工作表数据，Matplotlib 与 NumPy 实现基础图形、渐变、复合结构和极坐标绘制，Pillow 用于图像处理与总览输出。日常绘图不需要启动 Excel。

第 7 图参考完整工作表导出，重建单元格字符条与文本框；第 21 图参考完整截图，重建不同半径的 PPT 扇形。实现细节见[逐图复核记录](逐图复核记录.md)。

## 验证与已知差异

全部 30 张图已完成运行检查与逐张视觉核对，检查内容包括数据、画布、字体、颜色、标签、图形结构和布局。左右对照保存在 `逐图审查/`，逐图结论见[逐图复核记录](逐图复核记录.md)。

字体抗锯齿及少量标注位置仍存在差异，不承诺逐像素一致。代码使用 Windows 字体路径，跨平台字体适配尚未验证。重新运行批量脚本会更新对应生成图片；重新导出 Excel 参考图需要 Windows 上的 Microsoft Excel。
