# 《Excel 数据可视化——从图表到数据大屏》第二章：30 个图表 Python 复现

本项目读取第二章配套 Excel 工作簿中的数据，使用 Python 复现 30 个可视化图表。内容覆盖渐变柱形图、蝴蝶图、甘特图、水球图、南丁格尔图、仪表盘、子弹图和滑珠图等类型，并尽量保持原案例的数据、配色、标签和布局风格。

![30 个图表复现总览](30图复现总览.png)

## 完成情况

- 完成度：30/30
- 数据来源：`第二章 图表(前15).xlsx`、`第二章 图表(后15).xlsx`
- 第 1～6 图：每张图使用一个独立 Python 脚本
- 第 7～30 图：由 `复现第07至30图.py` 中的独立绘图函数生成
- 一键运行入口：`运行全部30图.py`
- Excel 参考图：`Excel参考原图/`
- 过程与验收记录：`复现进度.md`

## 环境要求

- Python 3.10 或更高版本（已在 Python 3.13 下验证）
- Windows 10/11
- 微软雅黑字体：`C:\Windows\Fonts\msyh.ttc` 和 `msyhbd.ttc`
- Python 依赖见 `requirements.txt`

代码使用 Windows 自带的微软雅黑字体路径，以保证中文标题和标签的外观接近 Excel 参考图。

## 安装依赖

建议在项目目录中创建独立虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

如果本机已有满足版本要求的 `matplotlib`、`numpy`、`openpyxl` 和 `Pillow`，可以直接使用现有 Python 环境，无需重复安装。

## 运行方法

一次生成全部 30 张图：

```powershell
python .\运行全部30图.py
```

单独生成第 1～6 图中的某一张，例如第 1 图：

```powershell
python .\复现第01图_渐变柱形图.py
```

生成第 7～30 图中的指定范围，例如第 15～20 图：

```powershell
python .\复现第07至30图.py --start 15 --end 20
```

第 7～30 图脚本还支持通过 `--front`、`--back` 和 `--output-dir` 指定前 15 图工作簿、后 15 图工作簿和输出目录。

## 实现说明

1. 使用 `openpyxl` 以只读方式提取 Excel 工作表中的业务数据。
2. 使用 `matplotlib` 和 `numpy` 绘制基础图形、渐变、组合图和极坐标图。
3. 使用 `Pillow` 处理部分图像与总览输出。
4. 将 Python 输出与 `Excel参考原图/` 中的参考图逐张对照，检查数据、画布、字体、颜色、标签和布局。

第7图使用完整工作表导出取得的有效参考，复现单元格字符条与文本框；第21图使用用户提供的完整截图重建不同半径的PPT扇形。旧的空白或缺失主体导出图不作为验收依据。具体来源与限制见[逐图复核记录](逐图复核记录.md)。
