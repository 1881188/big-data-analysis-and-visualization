# 第三章：动态图表

状态：7个案例已完成Python实现和自查，用户验收通过并同意推进第四章。本章纳入[课程GitHub仓库](https://github.com/1881188/big-data-analysis-and-visualization)。

现有参考文件：[第三章 动态图表.xlsm](../第三章%20动态图表.xlsm)。源文件暂保留在课程根目录。

本章使用 **Python + Matplotlib + Tkinter** 实现本地交互，不依赖运行Excel或启用宏。数据通过openpyxl直接读取原工作簿，筛选与聚合由Python完成，不使用截图冒充绘图。

## 运行

本机已安装所需依赖，不需要重新安装或新建环境。在PowerShell运行：

```powershell
python -X utf8 "第三章动态图表/app.py"
```

其他电脑在本章目录运行 `python app.py`。需保留上一级的原工作簿及文件名，依赖见[requirements.txt](requirements.txt)。已验证环境为Windows、Python 3.13、Matplotlib 3.10.1、NumPy 2.2.3、openpyxl 3.1.5、Pillow 11.1.0及Python自带Tkinter。中文字体使用微软雅黑、等线；非Windows系统需自行配置对应可用字体，未验证跨平台界面。

顶部选择案例，左侧调整条件，底部显示当前筛选。每个案例保留各自的选择状态。“恢复本图默认”只重置当前图的筛选参数。“导出当前PNG”在本章 `输出/手动导出/` 保存图片和同名JSON筛选记录，不覆盖先前导出。

## 代码结构

- `data_model.py`：原始数据读取、部门聚合、矩阵切片及默认状态。
- `charts.py`：7个可独立调用的Matplotlib绘图函数。
- `app.py`：桌面窗口、控件联动、恢复默认和导出。
- `export_previews.py`：批量出图及左右对照。
- `test_chapter3.py`：数据、图形和交互回归测试。
- `检查窗口布局.py`：短暂打开本程序，检查窗口边界，仅截图本程序客户区后关闭。
- `检查源工作簿.py`、`导出参考图.ps1`：源文件审查工具；后者仅生成参考图时需要Windows Excel，禁用宏并只读打开，退出不保存。
- [逐图验收记录.md](逐图验收记录.md)：逐例核对结论、已知差异和用户验收清单。
