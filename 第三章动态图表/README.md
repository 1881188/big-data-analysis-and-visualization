# 交互式图表｜第三章

[返回项目首页](../README.md)

## 模块简介

参考《Excel数据可视化——从图表到数据大屏》第三章，使用 Python、Matplotlib 与 Tkinter 实现 7 个交互式图表案例。通过月份选择、指标勾选、部门筛选和视角切换更新图表，并支持导出当前图片与筛选条件。

![交互式图表窗口](输出/交互窗口.png)

## 案例与功能

| 案例 | 交互方式 | 默认条件 |
| --- | --- | --- |
| 01 动态柱形图 | 1—6 月下拉选择 | 5 月 |
| 02 动态跑道图 | 1—4 月切换，同步显示人数 | 4 月，总人数 1637 |
| 03 动态南丁格尔圆环图 | 近 7 天／近 30 天切换 | 近 7 天 |
| 04 动态组合图 | 销售额、利润、利润率独立勾选 | 三项全选 |
| 05 透视表切片器 | 部门多选、全选、清空 | 市场拓展，600 条记录 |
| 06 动态玉玦图 | Python 单选按钮替代 VBA 按钮 | 近 30 天 |
| 07 动态滑珠图 | 按月份／按区域切换，各有 6 个选项 | 按月份，1 月 |

这里的“动态”指控件驱动的数据更新，不是自动播放动画。

## 环境与运行

已验证 Windows、Python 3.13、Matplotlib 3.10.1、NumPy 2.2.3、openpyxl 3.1.5、Pillow 11.1.0 与 Tkinter。中文字体使用微软雅黑、等线；跨平台字体与窗口适配尚未验证。依赖见 [requirements.txt](requirements.txt)，已有满足依赖的环境可跳过安装。

以下命令均在项目根目录执行：

```powershell
python -m pip install -r "第三章动态图表/requirements.txt"
python "第三章动态图表/app.py"
```

保留根目录的源工作簿及文件名。顶部选择案例，左侧调整条件，底部显示当前筛选；每个案例保留独立选择状态。“恢复本图默认”只恢复当前案例的筛选参数。

“导出当前PNG”在本章 `输出/手动导出/` 保存图片和同名 JSON 筛选记录，不覆盖先前导出。

## 实现方式

openpyxl 读取源工作簿，Python 完成筛选与聚合，Matplotlib 根据数据绘制图表，Tkinter 处理窗口与控件联动。透视表切片器和 VBA 按钮的交互逻辑在 Python 中实现，日常运行不需要启动 Excel，也不执行 VBA 宏。
