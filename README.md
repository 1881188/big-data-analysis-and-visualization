## 使用说明

进入具体实验目录，按照该目录 README 中的说明运行代码。本机已有所需Python依赖，无须重复安装。实验代码默认只读原始数据文件，生成结果保存在对应实验目录中。第三章提供Tkinter交互窗口，支持下拉切换、指标勾选和部门筛选，并附7张原图/Python逐图对照。

## 快速运行

推荐Windows桌面环境（图形代码使用微软雅黑字体）。下载或克隆完整仓库后，在项目根目录打开终端，使用已有且安装了各章依赖的Python环境：

```powershell
python "9.3第二章图复现/运行全部30图.py"
python "第三章动态图表/app.py"
python "第四章数据可视化看板/app.py"
```

第三、四章需要带Tkinter的本地桌面环境。依赖清单、数据口径和详细操作说明见各章README。运行代码不需要执行工作簿中的VBA宏。
