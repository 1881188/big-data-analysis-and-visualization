# Python 数据可视化｜从 Excel 图表到交互分析看板

用 Python 将 Excel 中的可视化案例转化为可运行程序，并进一步构建基于官方年度数据的交互分析看板。项目覆盖数据整理、指标计算、图表绘制、交互筛选和结果导出，提供代码、运行说明、效果截图与核验材料。

**30 个图表案例 · 7 个交互案例 · 2 个业务看板 · 1 个人口与能源交互看板**

第二至四章案例参考《Excel数据可视化——从图表到数据大屏》；人口与能源模块基于国家统计局公开数据独立设计。

## 人口与能源：15 年数据，10 张联动图表

从人口规模、城乡与年龄结构，到能源消费总量、品种结构和基期增量，在同一时间轴中观察 2011—2025 年的变化。主屏展示 9 张图，第 10 张热力图作为扩展分析视图。

[进入人口与能源项目 →](人口能源数据看板制作/README.md)

![全国人口与能源交互看板，默认 2025 年](人口能源数据看板制作/outputs/dashboard/看板_1920x1080.png)

- **统一交互**：年份播放、图表点击、基期比较、能源选择与数量／占比切换；趋势图保留完整历史背景。
- **完整数据链路**：保留官方原始响应、指标字典、清洗 CSV、来源清单与校验值，使用 Python 和 SQLite 完成查询与计算。
- **可解释的统计口径**：区分数量、比例、百分点和序列变化；缺失数据明确标注，品种折标量注明估算方法。
- **本地运行与导出**：Python 标准库启动服务，浏览器呈现图表；随附 ECharts 资源，支持 PNG、CSV 和 JSON 导出。

## 快速开始

下载或克隆完整仓库，以下命令均在仓库根目录执行：

```powershell
git clone https://github.com/1881188/big-data-analysis-and-visualization.git
cd big-data-analysis-and-visualization
```

### 人口与能源交互看板

Python 3.10 或以上及现代浏览器即可运行，无需安装 Python 第三方库或启动 Excel：

```powershell
python "人口能源数据看板制作/app.py"
```

程序自动打开浏览器，默认地址为 `http://127.0.0.1:8765/`。默认当前年为 2025、比较基期为 2011。按 Ctrl+C 关闭服务；端口占用时可追加 `--port 8766`。详细操作见[模块运行说明](人口能源数据看板制作/README.md#快速开始)。

### Excel 案例

推荐 Windows 桌面环境，已验证 Python 3.13。第三、四章需要 Tkinter，中文字体使用微软雅黑等；已有环境满足依赖时可跳过安装。

| 模块 | 安装依赖 | 启动／生成 |
| --- | --- | --- |
| 第二章 | `python -m pip install -r "9.3第二章图复现/requirements.txt"` | `python "9.3第二章图复现/运行全部30图.py"` |
| 第三章 | `python -m pip install -r "第三章动态图表/requirements.txt"` | `python "第三章动态图表/app.py"` |
| 第四章 | `python -m pip install -r "第四章数据可视化看板/requirements.txt"` | `python "第四章数据可视化看板/app.py"` |

保留源工作簿的文件名与目录关系。日常运行由 Python 读取数据并绘图，不执行 VBA 宏；重新导出 Excel 参考图的辅助工具需要 Windows 上的 Microsoft Excel。

## 数据与验证

Excel 案例按原图核对数据、配色、标签和布局；交互模块检查筛选状态与导出，业务看板检查全年月份聚合与组件渲染。字体和部分细节可能与参考图存在差异，具体口径修正在各模块中说明。

人口与能源模块保留 40 项原始指标及来源记录，当前展示 2011—2025 年。**2024、2025 年的人均生活用能在当前数据源中缺失**，对应图表保留空值并明确提示，其他已有指标正常显示。7 组后端测试覆盖 960 种有效筛选组合；15 项浏览器检查覆盖真实点击、年份播放、数据导出及多尺寸布局，10 张图均已逐图检查。
